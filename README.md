# Fitlog

## Short Description

Fitlog is a workout management web application where users can explore workouts, view workout details, and manage their selected workouts.

## Technologies Used

* Next.js
* React
* TypeScript
* Tailwind CSS
* Context API
* REST API
* Local Storage
* Daisy UI
* React Icons


## Key Features

1. **Workout Library** – Browse different workouts with useful information.
2. **Workout Details** – View detailed information and instructions for each workout.
3. **Workout Selection** – Add workouts to your personal workout list.
4. **State Management** – Manage selected workouts using Context API.
5. **Local Storage** – Save selected workout data in the browser for persistence.
